# AI Usage Popup

Popup GTK simples para visualizar uso de Claude, Codex/OpenAI, Z.AI, OpenRouter e outros usando `ai-usagebar`.

## Arquivos
- `ai-usage-popup` — script principal
- `ai-usage-popup.desktop` — launcher desktop

## Rodar manualmente
```bash
./ai-usage-popup
```

## Requisitos
- `ai-usagebar`
- Python 3
- GTK3 (`python3-gi`)

## Observação
O app lê os vendors através do binário `ai-usagebar` instalado no usuário.
